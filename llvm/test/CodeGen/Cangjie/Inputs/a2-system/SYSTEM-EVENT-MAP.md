## Root-map and ABI boundaries

`recordStatepoint` no longer writes qualification. `recordCJStackMap` consumes the actual call PC for the currently reinstated source MI; a preserved non-call map alone never qualifies a caller. Allocation's callback and slow branch have separate qualification rows; only the existing semantic graph production points create G. Existing absent graph, suppressed empty ordinary map, explicit empty return map and nonempty map remain distinguishable.

MC same-PC/same-kind duplicate rejection is unchanged, including equal-bits duplicates; there is no deduplication/selection by bits. Return roots/flag, version0x80000001, 48/56 descriptor sizes, qualification tag/header/8-byte row/kind1/2/3, entry slot and compressed map format are unchanged by this stage. A cross-format consumer or raw/generic semantics cannot be called complete from this source table.
